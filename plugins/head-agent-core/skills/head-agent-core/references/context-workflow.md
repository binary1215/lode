# Selected Context preparation

For new project information, use a short `head_project_graph` result first or
reuse sufficient same-basis evidence, then inspect original sources.
Expand returned anchors with `details: true` only when useful.
Ordinary reading, fixes and Host delegation need no Capsule or inclusion proof.

When selected-context handoff is useful, `head_context_prepare` accepts the
exact user task and returns selected records, sources, omissions and uncertainty.
It is a single read-only preparation, not a prerequisite for every task.
`head_context_preview` optionally accepts Lode-authored EvidenceNeeds or exact
current graph anchors. Users never fill JSON, select IDs or operate a budget ladder.

Lode assesses relevance and sufficiency. `ready_for_head_semantic_assessment`
does not assert that requested evidence is present or complete.
Read `evidenceGaps`, `omissions` and `uncertainty`, inspect original source
bodies and expand only missing useful material. Budget is any positive safe integer,
default 32768 approximate tokens; there are no compulsory tiers or proof retry chain.
Actual provider fit and output reserve are separate runtime constraints.

Missing or stale World is disclosed, not a global gate. Use current local source
inspection without Product onboarding or full indexing. Exact stale graph requests
fail only their dependent operation. Persist a Capsule only when durable handoff,
Run or recovery actually needs it. Context never approves a result or writes P2 direction.

For historical state, use bounded `head_graph_lineage_status`,
`head_graph_lineage_trace` and `head_graph_lineage_diff` views. Preserve original
Project, revisions, candidate state, provenance and coverage. A content-equal
possible move is not semantic identity.

Optional Observation, delivery, Policy, Conformance or mapping work is not a
setup checklist. Reuse sufficient facts and keep ordinary inspection ephemeral.
Read [optional Product evidence](conversation-ux.md#optional-product-evidence)
only when the task needs that outcome. No extra forms or universal review.
