Go runtime and standard-library notices

The native worker, supervisor and read-only bridge are built with Go using
CGO_ENABLED=0. This file preserves notices for the Go runtime/standard library
and selected source components that may be linked for supported targets; it is
not a claim that every listed symbol is linked in every binary.
The plugin's own MIT license remains in the root LICENSE file.

Sources below are from https://github.com/golang/go/tree/go1.26.0 .
The same Go BSD text also appears in the vendored golang.org/x/crypto, net,
sys and text LICENSE files; it is reproduced once here.
