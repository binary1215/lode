## 민감한 문제 신고

민감한 문제는 [GitHub 비공개 취약점 신고](https://github.com/binary1215/lode/security/advisories/new)를
이용하세요. 이 저장소의 비공개 취약점 신고 기능은 활성화되어 있습니다.
신고하려면 GitHub에 로그인해야 하며 별도 이메일 주소는 지정하지 않습니다.
자격 증명, OAuth 토큰, 비공개 저장소 내용, 작업 원문이나 악용 가능한 세부 사항을
공개 이슈 또는 내보낸 보고서에 게시하지 마세요.
대응 SLA나 보안 지원 기간을 여기서 약속하지 않습니다.

민감하지 않은 재현에는 합성 저장소를 사용하고 소스·패키지 버전, 영향을 받는
작업, 기대 동작과 실제 동작, 민감한 부분을 제거한 근거를 포함하세요.
설치 파일과 활성 Host/MCP 연결을 구분하세요. 베타 표기나 CI 성공은 보안 보증이 아닙니다.

## 현재의 경계

- 그래프·인덱스·Explorer HTML은 파생 뷰이며 승인, 실행 권한이나 복구 방향이 아닙니다.
  [권한 평면](docs/ko/authority-plane-contract.md)을 참고하세요.
- 내보낸 원문에는 민감한 내용이 포함될 수 있습니다. Explorer 공유 모드는 생성된
  머신 메타데이터만 생략하며 원문을 익명화하지 않습니다.
  [Graph Explorer](docs/ko/graph-explorer.md)를 참고하세요.
- 정확한 소스 digest, 경로 검사, 읽기 범위와 네이티브 프로세스 소유 검증을 유지하세요.
  거부된 작업을 다른 도구로 우회하거나 재현을 통과시키려고 검사를 약화하지 마세요.
- 마켓플레이스 게시, 검증된 패키지 파일, 실제 Host 로드는 별도 관측입니다.
  [설치 안내](README.ko.md)를 따르세요.
