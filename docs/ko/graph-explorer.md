# Graph Explorer

> 영어 원문: [graph-explorer.md](../graph-explorer.md)

Graph Explorer는 기존 Lode 근거를 로컬에서 읽기 전용 그림으로 보여줍니다.
목적이나 기록된 판단에서 관련 소스·관계·결과·남은 질문을 따라갈 때 사용합니다.
선택 기능이므로 일반 작업이나 복구를 위해 이 화면을 거칠 필요는 없습니다.

## 스냅샷 열기

Lode에 “이 프로젝트의 로컬 그래프 스냅샷을 만들어 줘”라고 요청하세요.
내보내기가 포함된 배포본에서는 에이전트가 플러그인 디렉터리에서 다음을 실행할 수 있습니다.

```powershell
node scripts/lode.mjs graph-explorer "<project-directory>"
node scripts/lode.mjs graph-explorer "<project-directory>" --query relay --history
node scripts/lode.mjs graph-explorer "<project-directory>" --share
```

반환된 HTML 파일을 브라우저에서 엽니다. 서버·계정·데이터베이스 설정이나
Session 바인딩은 필요하지 않습니다. 기본 출력은 운영체제 임시 디렉터리에
새로 만듭니다. 선택 사항인 `--output`으로 새 보고서 파일을 지정할 수 있지만,
기존 파일이나 정본·런타임 디렉터리는 덮어쓰지 않습니다. 명시적으로 생성할 때
보고서 하나를 만들며, 아티팩트를 자동으로 계속 생성하지 않습니다.

실행 파일은 플러그인에 있지만 `<project-directory>`는 현재 작업 중인 대상
프로젝트입니다. 항상 명시하세요. Project·World·소스 근거가 없으면 없다고 표시하며,
Lode 코드나 데모 그래프로 대체하지 않습니다.

HTML과 내보내기 결과는 UTF-8 파일의 정확한 바이트 크기와 리소스 안내를 표시합니다.
큰 보고서는 브라우저 메모리와 시간이 많이 들 수 있지만 경고로 기록을 자르거나
크기 게이트를 추가하지 않습니다.

`--share`는 자동 생성된 `project.root`, 재생성 명령의 로컬 실행 파일·Project 인자,
원문 확장 힌트의 `project_root`만 제외합니다. ID·digest·원문·과거 인용·근거는
지우지 않으므로 원문 자체에 절대 경로나 기밀 정보가 남을 수 있습니다. 공유 전에
직접 확인하세요. 익명화 기능이 아니며, 일반 내보내기는 로컬 메타데이터와 안전하게
인용된 재생성 명령을 유지합니다.

## 기록된 판단 따라가기

따라가고 싶은 작업이나 검토를 요청하세요. 기존 내보내기에 정확한 기록 ID와 소스
경로를 전달할 수 있으며 Run이나 별도 승인을 요구하지 않습니다.

```powershell
node scripts/lode.mjs graph-explorer "<project-directory>" --anchors "<exact-work-or-review-id>" --paths "src/service.mjs"
node scripts/lode.mjs graph-explorer "<project-directory>" --layer code --anchors "<exact-structural-node-id>"
```

명시한 ID가 상세 묶음을 선택하며, 선택한 작업의 저장된 소스 인용도 읽습니다.
사용 가능한 검증된 탐색 메타데이터 전체는 계속 검색할 수 있습니다. 비교에서는
전후 각각의 정확한 경로·digest를 인용한 작업을 선택 여부와 관계없이 찾을 수 있습니다.
Read citing work로 해당 기록에 돌아가되, 인용을 변경 원인으로 주장하지 않습니다.
문서 인용은 검증된 원본 문서에 연결하며 그 안의 모든 결정·후보를 인용했다고
확대하지 않습니다. 저장된 부모·수정 생성·검토 관계의 방향을 유지하고, 후보를 만든
revise 결정과 후속 후보를 승인한 결정을 구분합니다.
Source 계층 ID는 구조 그래프의 별도 신원으로 유지하고 해당 계층에서 다시 엽니다.
같은 검증 스냅샷의 경로·digest가 일치할 때만 소스 상세를 선택하며 Project 노드나
계층 사이 관계를 만들지 않습니다. 명시한 ID가 없으면 무관한 첫 기록을 대신 선택하지 않습니다.

상세가 없으면 Exact detail options에서 정확한 ID로 새 보고서를 요청하는 방법을
보여줍니다. HTML이 명령을 실행하지는 않습니다. 새 보고서는 새 기준에서 근거를
다시 읽으며 이전 스냅샷에 몰래 합치지 않습니다. 상세 미포함은 작업이나 변경의
부재가 아닙니다. 포함된 정확한 원문에서 결과의 검증·근거·영향 범위와 검토의 후속
조치를 읽을 수 있지만, 이는 저장된 주장이지 뷰어가 재실행한 검사나 새로운 실행
권한이 아닙니다. 탐색 발췌와 구조화 원문의 잘림을 표시하며 원본 전체에도 별도의
읽기 범위와 미포함 상태가 있을 수 있습니다.

## 근거 탐색

Project 계층에는 기록된 목적·결정·작업·보존된 계보가 나옵니다. Source 계층에는
기존 코드 그래프의 import와 call이 나옵니다. 두 계층의 원래 식별자와 기준을
유지하며, 경로가 같다고 새 관계를 만들지 않습니다. Product와 Work는 공유된
근거의 필터이지 서로 다른 데이터베이스가 아닙니다.

검색·지도·목록에서 기록을 고릅니다. 클릭이나 Enter는 선택에 추가하고 읽기 초점을
옮깁니다. 카메라를 움직이거나 이웃을 펼치지는 않습니다. Ctrl/Cmd 클릭·체크박스·
Space로 선택을 토글하며 Clear selection과 Select only focus는 명시적으로 사용합니다.
지도 배경에서 Shift 드래그하거나 Rectangle select를 켜면 보이는 기록을 추가합니다.
목록과 키보드로도 같은 집합을 선택할 수 있습니다. Escape는 기존 선택을 지우지 않고
진행 중인 제스처나 계산을 취소합니다.

Open direct connections, 지도 제목 더블클릭, 지도 카드에서 Shift+Enter는 선택한
기록의 정확한 한 단계 이웃만 엽니다. 반복해도 다음 경계로 넘어가지 않습니다.
이웃이 많으면 제어권을 돌려주며 취소할 수 있고 첫 화면 위치만 준비합니다.
나머지 기록과 관계 페이지는 계속 접근할 수 있습니다. 선택·핀·기존 좌표를 유지하며
명시적인 펼치기만 읽기 좋은 카드로 중심을 옮길 수 있습니다. 일반 Read는 카메라를
유지하고, 계산 도중 사용자가 이동·확대한 카메라를 완료 시 덮어쓰지 않습니다.

Expand next boundary는 선택 집합에서 아직 보이지 않는 다음 경계를 추가합니다.
반복하면 같은 한 단계 이웃만 다시 여는 대신 이미 노출된 경계를 넘어갑니다.
관계·종류 필터로 범위를 정할 수 있습니다. 기존 노드·고정 위치·카메라·지도 모드를
유지하고 새 기록의 자리만 잡습니다. 화면 밖에 추가된 기록은 목록이나 명시적
중앙 이동·맞춤 도구로 찾습니다. Fold last addition은 마지막 추가분만 접으며,
공유·선택·고정된 기록과 원래 보이던 기록은 남깁니다. 뒤로·앞으로는 ID를 다시
방문해 펼치는 대신 선택·범위·모드·카메라의 기록된 화면 단계를 복원합니다.
수동 고정 위치는 유지합니다.

코드 이웃은 수평으로, 목적·제품·운영 기록은 수직으로 펼칩니다. 축은 화면 배치
지침이지 새 위계나 가공의 관계가 아닙니다. 이미 펼친 노드는 위치를 유지합니다.
카드 머리글을 끌거나, 카드에 초점을 두고 `Shift`와 방향키를 눌러 화면 위치를 고정합니다.
뒤로·앞으로와 탐색 경로를 통해 이전 화면 단계로 돌아갑니다. 이는 임시 화면 상태이지
제품 지식에 저장되는 선택이 아닙니다.
새 노드의 자동 배치는 카드 사각형을 함께 피하며, 연결되지 않은 기록에서
탐색을 시작할 때도 빈 공간을 찾습니다. 직접 드래그하면 의도적으로 겹쳐 놓을 수
있으며, 다른 노드를 펼칠 때 사용자가 정한 위치를 되돌리지는 않습니다.
처음에는 기본 기록과 시작 이웃이 자동으로 열립니다. Focus selection은 읽기 초점을
명시적으로 중앙에 놓으며, 화면 밖 연결도 전체 연결 목록에서 페이지로 탐색합니다.
직접 관계의 **Show on map: endpoint**를 누르면 다른 선택과 고정 좌표를 유지한 채
해당 기록을 읽기 좋은 카드 크기로 보여줍니다. 뒤로·앞으로는 그 카메라 단계를
복원합니다. 이 명시적 이동이 필터를 넓히지는 않으며, 현재 범위 밖 endpoint에는
기존의 범위 복구 안내를 유지합니다.
Explored map은 지금까지 펼친 기록을 맞춰 보여줍니다. All evidence는 내보낸 전체
목록을 Canvas 개요로 보여주므로, 기록마다 SVG 요소를 만들지 않습니다. 점을 고르거나
정확한 ID를 검색하면 해당 기록에 초점을 둡니다. 검색은 내보낸 모든 기록을 대상으로
하며 목록과 연결의 페이지 크기는 내보내기 상한이 아닙니다. 필터로 숨긴 이웃,
화면 밖 이웃, 내보내지 않은 끝점을 따로 셉니다. Start here는 임시 탐색 경로만
초기화합니다. 검색은 일치 항목을 강조하고 결과 목록을 좁힙니다. 불일치 항목 숨기기는
별도 체크박스입니다. 과거·축·뷰 필터는 그대로 적용하고 범위 밖 선택은 보존해
표시합니다. Show selected scope는 명시적으로 범위를 복원하며 과거 근거를 몰래
활성화하지 않습니다. SVG와 Canvas는 크기 변경을 포함하여 그리기·포인터 판정·
사각형 선택에 같은 카메라 변환을 씁니다. Canvas 점을 골라도 개요에서 나가지 않습니다.
노드 사이 거리는 관련성 점수가 아닙니다.

탐색 집합이 화면에서 읽을 수 있는 카드 수를 넘으면 Explored map은 수천 개의 작은
카드 요소를 만드는 대신 기존 Canvas로 탐색한 부분 집합을 보여줍니다. 상태 표시는
전체 인벤토리를 보여주는 All evidence와 이를 구분합니다. 기존 카드 좌표와 핀은
그대로 두며, 기록을 선택한 뒤 Focus selection으로 읽을 수 있는 카드에 돌아옵니다.
기록·관계 상한이 아니라 화면 상세도 선택입니다. 대량 배치도 혼잡한 후보 위치를 찾는
도중에 제어를 양보하고, 취소·대체된 맞춤이 나중에 현재 화면을 덮어쓰지 않습니다.

기본은 현재 근거입니다. Include historical / non-current evidence를 선택하면
보존된 과거 기록과 정확한 관계를 원래 상태와 함께 탐색할 수 있습니다. 이 선택이
과거 근거를 현재로 바꾸거나 실행을 승인하지는 않습니다.

요약이 없는 작업 기록도 펼치면 저장된 관측과 후속 제안을 읽을 수 있습니다. 지도 카드는
발췌를 보여주며, 읽기 카드는 내보낸 구조화 내용과 부분 발췌의 정확한 필드·범위 표시를
유지합니다. 이는 에이전트가 작성한 기록이지 사용자 발언 캡처나 실행 권한이 아닙니다.
참조만 있는 근거와 메타데이터만 있는 투영은 안내를 구분합니다. 정확한 원문의 생략·조회
실패 코드는 별도로 남으며, 요약이 없다는 이유로 원문 부재를 단정하지 않습니다.
스냅샷 조회 안내는 World ID만이 아니라 조회 방식과 기록된 World·Source·Graph 전체
끝점이 일치하는 비교에만 표시합니다.

선택한 기록은 개별적으로 접힌 읽기 카드로 함께 남습니다. 읽을 카드만 펼치며 다른
기록을 선택해도 모든 본문이 자동으로 열리거나 앞선 카드가 사라지지 않습니다.
다른 선택의 추가·제거, 초점·필터 변경, 뒤로·앞으로, 페이지 왕복에서도
영향받지 않은 카드의 펼침·스크롤을 이 HTML 안에서 보존합니다. Project·계층·revision
별로 상태를 분리하며, 식별 근거가 부족한 항목만 읽기 상태를 새로 시작합니다.
본문 읽기를 막지는 않습니다. Widen reading area로 읽기 영역을 넓히며 좁은 화면에서는 세로로 쌓습니다.
카드·기록·참조 페이지는 표시 단위이지 선택이나 근거 상한이 아닙니다. 각 카드나
초점 연결 목록에서 실제 방향 있는 관계를 읽습니다. 정확한 원문·알 수 없는 필드·ID는
선택적 상세로 유지합니다. 잘림·결손·취소·미검토 상태는 펼친 내용 가까이에 보존하며
카드를 접었다고 버리지 않습니다. 과거 Session을 선택해도
그림만 바뀝니다. 내보내기는 네이티브 Host의 선택을 추정하거나 실제 작업의
Session을 변경하지 않습니다.

## 내용 카드와 기록된 그룹

초점·탐색 지도는 기록된 제목과 작은 + 펼침 조작만 먼저 보여줍니다. 카드를 열면
유형·기존 본문 발췌·조건·출처·알려진 소속을 읽고 −로 다시 접습니다. 지도와 읽기
카드의 펼침은 독립적인 화면 선택이지 근거나 권한의 변경이 아닙니다. Read full
record는 해당 독립 읽기 카드를 엽니다. 새 요약이 아니라 기존 표현을 보여줍니다.
펼친 작업 기록은 에이전트가 작성한 근거로 표시하며 사용자 발언
원문이나 실시간 완료로 취급하지 않습니다. 알려진 미해결·취소·제약·미검토·부분
자료·과거 조건은 줄인 본문과 따로 표시합니다. 자유문장 뒤의 예외는 발췌 밖에
있을 수 있으므로 전체 표현은 선택한 기록과 정확한 원문에서 읽습니다. 없는 본문을
만들지 않으며 원시 메타데이터는 선택적 상세입니다.

그룹은 검증된 작업 루트 선언 또는 같은 정확한 소스·모델 기준의 Product/World
FeatureGroup 직접 소속으로만 구성합니다. Session·이름·경로·시각·일반 포함 관계가
같다는 이유로 묶지 않습니다. 다중 소속이어도 정확한 노드당 카드 하나만 표시하며,
읽기 카드에서 알려진 모든 소속과 직접 기록된 구성원을 확인합니다. 전이 소속·가짜
간선·주 소속·그룹 편집 기능은 만들지 않습니다. 표시 구성원과 내보낸 구성원의 수를
구별합니다. 그룹 배경은 펼친 구성원이 있을 때만 나타나고 실제 보이는 구성원
사각형만 둘러싸며 공유 구성원이나 무관한
카드 때문에 오해를 만들면 닫힌 상자 대신 제목·개수·소속 목록을 사용합니다.
그룹은 선택적 배치 힌트이지 위계나 권한이 아닙니다.

펼친 본문의 텍스트 선택과 내부 스크롤은 카드 이동이나 지도 확대를 일으키지 않습니다.
펼침 버튼은 기록을 선택하거나 고정하지 않으며 Enter/Space의 기본 버튼 동작을
보존합니다. 머리글 드래그·배경 이동·Shift
사각형 선택·키보드 조작을 구분합니다. 사각형 선택은 카드 모서리만 양의 면적으로
겹쳐도 선택하며, 전체 Canvas 개요는 기존 점 선택을 유지합니다. 간선의 실제 방향과
평행·자기 연결 및 typed 목록은 보존하고 화살표는 불투명 카드 경계 밖에서 끝냅니다.
화면 관련 카드·간선만 지도 DOM으로 만들며 화면 밖 근거는 전체 페이지 목록에 남습니다.

일반 펼치기는 새 기록만 배치합니다. 지속적인 물리 시뮬레이션이나 재정렬 버튼은
없습니다. 화면 밖에 놓을 카드도 최초 배치 전에 표시 HTML을 측정합니다. 시작 카드를
먼저 보여주고 직접 이웃이 많으면 제어권을 돌려주는 취소 가능한 배치로 측정·배치합니다.
준비 중에도 전체 목록·검색·일반 읽기를 사용할 수 있으며 새 명시 작업은 기존 준비를
대체합니다. 미배치 위치는 화면 밖 위치와 따로 세며 완료된 배치로 표시하지 않습니다.
아직 탐색하지 않은 전체 목록의 본문을 먼저 측정하지 않습니다. 이동·초점·일반 지도
확대·최초 화면 진입은 완료된 기하를 재사용합니다. 글꼴·가용 폭이 바뀌면 영향받는 크기를 갱신하고 필요한 경우
영향받는 미고정 좌표만 임시 계산에서 조정합니다. 완료 후 함께 적용하며 취소하면
직전 기하를 유지하고 같은 크기 계산을 즉시 재실행하지 않습니다. 이후 실제 측정
기준이 바뀌면 다시 계산할 수 있습니다. 크기 계산 취소나 의도적으로 겹친 핀 때문에
본문이 겹칠 수 있어도 독립 읽기 카드는 계속 이용할 수 있습니다. 카메라·핀·무관한
읽기 상태는 보존합니다. Ctrl/Cmd 휠은 브라우저의 접근성 확대용으로 남깁니다.
영속 UI 저장·외부 글꼴 조회·서버는 추가하지 않습니다.

지도 카드를 열고 접을 때는 새 크기를 측정하고 필요할 때 그 미고정 카드만 조정하며
현재 화면의 빈 공간을 우선합니다. 다른 좌표·핀·카메라는 유지하고 고정된 겹침을
몰래 풀지 않습니다. 펼친 본문에는 내부 스크롤과 전체 기록 읽기 동작이 있습니다.
펼침 계산을 취소하면 직전의 완료된 표시 상태를 유지합니다.

Show selected connections는 현재 내보내기 계층과 명시적 필터 안에서 양방향 인접
관계를 탐색합니다. 연결된 각 성분마다 선택한 초점, 그것이 없으면 안정적인 첫 선택을
참조로 고정합니다. 그 참조에서 같은 성분의 다른 선택까지 최단 연결 가지들의 합집합을
보여주며 동률 선행 관계와 원래 관계 방향·종류를 모두 보존합니다. 모든 경로를
열거하거나 전역 최소망을 찾는 기능이 아니며 인과·방향 있는 실행·승인·완료를
증명하지 않습니다. 연결되지 않은 성분은 분리하고 더 긴 가지는 일반 펼치기로
탐색합니다. 읽기 초점만 바꿔서는 참조나 결과를 재계산하지 않습니다. 선택·필터가
바뀌면 명시적으로 다시 계산하기 전까지 이전 결과임을 표시합니다. 큰 계산은
화면에 제어권을 돌려주며 취소할 수 있고, 미완료 계산을 완료 결과로 표시하지 않습니다.

보존된 이력은 임시 탐색 경로와 다른 기능이며 선택 사항입니다.
보존된 이력의 제한된 페이지와 가능한 경우 정확한
스냅샷 비교를 표시합니다. 보존된 두 ID만으로 시간 순서나 인과관계를 주장하지
않습니다. 이력이 없으면 사용할 수 없다고 표시하며, 화면을 열면서 이력을
갱신하거나 새로 만들지 않습니다.

## 그림이 알고 있는 범위

생성 시각·스냅샷 기준·범위·누락을 계속 표시합니다. 실시간 화면이 아닙니다.
검색 결과가 비어 있어도 다른 근거가 없다는 뜻은 아닙니다. 과거 revision을
현재 파일로 바꿔 보여주지 않습니다. 예상 digest와 다르면 정확한 revision의
원문을 사용할 수 없다고 표시합니다. 코드가 오래됐으면 원래 소스로 돌아가는
경로를 유지하면서, 다른 검증된 기록은 계속 보여줍니다.
공통 코드 비교 reader는 별도로 검증된 보존 소스 관측에서 정확한 과거 바이트를
찾은 뒤 로컬 Git을 시도합니다. Project·경로·digest·UTF-8 검증을 유지하며 탐색
한도나 원문 결손을 명시합니다. 현재 파일 없이 과거 before만 남아 있다는 사실은
삭제·Run의 행위·변경 원인을 입증하지 않습니다.

일반 그래프 질의는 반환 기록과 관계 endpoint의 현재 소스 바이트를 관측하며,
Explorer 목록은 반환 목록 전체를 관측합니다. 반복 그래프 검증은 요청이 소유한
검증된 불변 복사본에만 재사용합니다. 파일 mtime이나 호출자가 제시한 그래프
hash를 신뢰하는 캐시가 아니며, 다음 요청에서는 현재 소스 바이트를 다시 확인합니다.

뷰어 목록에는 고정 노드·관계 개수나 임의의 HTML 크기 상한을 두지 않습니다.
기존 typed reader로 사용할 수 있는 계층을 검증하며, 손상된 계층이나 소스 읽기의
자원 한도 때문에 불완전한 경우에는 그 범위를 표시합니다. 일반 대화용 그래프
조회의 기존 한도는 유지합니다.

오프라인 HTML은 반복 메타데이터를 손실 없는 표 형태로 저장하고, 열 때 동일한
JSON 기록으로 복원합니다. 전송 크기만 바뀌며 근거의 ID·필드·중복 항목·권한은
바꾸지 않습니다. 큰 보고서를 복원할 메모리는 여전히 필요하며, 내보내기 성공이
브라우저 속도를 보장하지는 않습니다.

정확한 원문은 파일당 64 KiB·합계 256 KiB로 제한합니다. 내보내기 질의에 맞는
상세 묶음을 포함할 뿐, 모든 원문이나 과거 비교 전체를 담는 것은 아닙니다.
메타데이터만 포함된 기록은 가까이에 그 사실과 새 보고서를 만드는 인용 처리된
명령을 표시합니다. 상세가 없다고 변경이 없다는 뜻은 아닙니다. Show recorded code
changes에서는 기존의 정확한 비교를 열어 일부 구간의 추가·삭제 행과 전후 원문을
확인합니다. 잘림과 기록 당시 after·현재 파일의 구분을 유지하며, 파일 전체 diff나
의미 판정으로 주장하지 않습니다. 조회·원문 읽기·렌더링 비용은 별도로 측정합니다.

Source 계층도 같은 Project에서 이미 내보낸 정확한 비교를 공유합니다. 소스 경로와
digest가 함께 일치해야 연결하며 같은 경로라는 추측이나 다른 계층의 우연히 같은
ID로 연결하지 않습니다. 포함된 경우 펼친 읽기 카드의 Recorded code context가
해당 파일 맥락을 열고 Show recorded code changes는 공통 비교 패널을 엽니다.
선택만으로는 패널을 열지 않으며 사용자가 열어 둔 상태는 유지합니다. 파일·변경 구간
이동은 해당 비교를 명시적으로 엽니다. 제한된 상세가 없으면 사용 불가로 남으며
새 질의 중심 내보내기가 필요할 수 있습니다. HTML이 실행 중 원본을 읽지는 않습니다.

선택한 변경과 여러 파일을 함께 읽습니다. 기존에 정확히 연결된 비교 쌍만 표시합니다.
기록된 스냅샷 전후·인용 A/B·인용 revision과 내보내기 시 관측한 현재 파일을 구분합니다.
클릭·선택 순서, 같은 경로, 시각만으로 비교 쌍이나 요청 경계를 만들지 않습니다.
각 비교의 버전·출처와 시각 결손·잘림·사용 불가 상태를 유지합니다. 비교 없는 파일도
남겨 둡니다. 이전·다음 파일과 변경 구간 도구는 다른 비교를 닫거나 없는 구간을
만들지 않고 열린 비교 사이를 이동합니다. HTML은 파일·Git·네트워크를 실시간으로
읽지 않습니다.

## 로컬 데이터와 권한

HTML에는 실제 소스 일부와 기록된 결정이 들어 있습니다. 공유할 때 저장소
자료처럼 다루세요. 런타임 fetch·CDN·텔레메트리·외부 이미지·로컬 서버를 쓰지
않습니다. 저장소의 신뢰하지 않는 텍스트는 제한적인 콘텐츠 보안 정책 아래
텍스트로만 표시합니다. 명시적 로컬 읽기 전용 어댑터를 사용하여 설정된 원격
그래프 저장소를 이용하지 않습니다.

그림은 P4 파생 보기입니다. 행동 승인·후보 승격·체크포인트 기록·Session 복원·
효과 재실행·원본 변경을 할 수 없습니다. 기록된 완료와 과거 검토의 원래 의미를
유지합니다.

기반 reader는 [그래프 우선 탐색](graph-discovery.md)과
[시간 출처](temporal-provenance.md)에서 설명합니다.

[기록된 맥락 보기](context-lineage.md)에서는 선택한 작업 기록에서 인용한 코드·문서로
이동하며 정확한 버전의 제한된 비교, 기록된 이유와 근거 결손을 확인합니다. 알려진
원본 본문은 읽기 쉽게 보여주며 원본 JSON과 알 수 없는 필드는 선택적 진단으로
유지합니다. 인용을 반영 완료의 증거로 바꾸거나 HEAD 작업 기록을 사용자 발언
원문으로 바꾸지는 않습니다.

## 접을 수 있는 도구와 현재 없는 경로

좁은 화면에서는 지도를 먼저 두고 근거 표시·선택 도구를 처음에 접습니다. 도구와
내보낸 전체 메타데이터는 계속 이용할 수 있습니다. 기존 원형 라벨 대신 카드를 쓰며
글자 모양을 고정 캡션 폭에 억지로 압축하지 않습니다. 글꼴·폭을 명시적으로 모형화한
검사까지 포함해 소스·VM 검사는 실제 브라우저 배치·모바일 가독성·200% 글자 확대·
실제 제스처·성능의 증명이 아닙니다. 이전에 수용된 합성 reader GUI 범위만으로
이번 후속 배치·모바일·대규모 그래프 동작까지 입증되지는 않으며 별도 실제
브라우저 검증이 필요합니다.

추가 선택은 정확히 같은 비교쌍의 diff 펼침·파일·변경 구간·스크롤을 유지하며,
다른 비교쌍으로 상태를 넘기지 않습니다. 레이어 이동은 무관한 첫 항목 대신
정확한 소스 신원을 사용합니다. 필터로 숨겨진 선택도 이름과 복원 동작을 유지하고,
상세·diff·지도 바로가기로 좁은 화면의 왕복 거리를 줄입니다. 제목만 기본 표시는
유지합니다.

초기 배치는 현재 화면을 우선하지만 전체 메타데이터와 직접 이웃 목록을 자르지
않습니다. 명시적인 확장과 탐색 지도 배치로 나머지도 접근할 수 있습니다.
초기·크기 변경 배치는 원자적 반영 전에 양보하므로 취소나 글꼴 측정 변경이
부분 좌표를 반영하지 않습니다. 전체 지도 geometry 캐시와 화면 밖 관계 그리기
생략은 그리기 비용만 줄이며 관계 존재를 바꾸지 않습니다. 소스·모형 검증은
60fps나 메모리 절감의 증거가 아닙니다.

현재 경로가 없더라도 정확한 인용 digest를 통해 로컬 Git의 당시 원시 바이트를
범위 안에서 찾을 수 있습니다. 이 원문 발췌는 이후 버전과 별개이며, 빈 diff를
만들거나 삭제를 확정하지 않습니다. 권한·경로·인코딩·바이트 상한 오류에는 이
fallback을 적용하지 않습니다. 기존 소스·Git 명령 상한을 유지하며 로컬 객체가
없어도 네트워크로 가져오지 않습니다.

선택적인 rename 후보는 가장 최근의 기록된 경로 변경, Git의 동일 바이트 이동
관측과 인용 digest를 사용합니다. 이는 역사 근거이며 검증된 논리적 연속성,
현재 경로의 가용성, 요청 이행이나 원인이 아닙니다. 내용이 바뀐 이동이나 기록되지
않은 이동은 추정하지 않습니다. 후보 조회는 주요 원문 조회 뒤에 수행하여 그 명령
예산을 먼저 소비하지 않습니다.

### 문서의 명시적 링크 따라가기

정확하게 인용된 Markdown 설계 문서는 기록 맥락 패널에서 명시적인 로컬 inline 링크를
보여줍니다. 인용 문서 버전에서 구현·테스트 발췌나 함께 포함된 다른 문서의 참조로
이어 읽습니다. 패널의 열림·읽기 위치를 유지하고 링크 탐색으로 지도 카메라를 움직이지
않습니다. 이미 export된 대상 기록은 선택할 수 있지만, 구현·승인처럼 보이게 하려고
그래프 노드나 관계를 새로 만들지 않습니다.

공통 source reader로 인용 digest의 정확한 원문에서만 링크를 추출합니다. 옛 문서가
없으면 unavailable이며 현재 문서로 대체하지 않습니다. 대상 digest가 없는 링크는
**그 경로의 현재 파일**입니다. 문서를 Git에서 찾았어도 대상의 과거 버전까지 증명된
것은 아닙니다. 각 참조에 문서 digest와 line/column을 남깁니다. 같은 버전은 읽기를
공유해도 각 출처 위치를 보존하며 다른 digest는 별도 근거입니다.

탐색은 소스 읽기 32회, 링크 64개, 깊이 2, 전달 원문 256 KiB, 대상 발췌 512자로
제한합니다. 선택 보고서의 자원 상한이며 의미적 충분성이나 권한 게이트가 아닙니다.
개수·대기 경로·깊이/바이트 상한·발췌 누락을 표시합니다. 명시 inline Markdown 링크를
지원하며 fence·들여쓰기·inline code, 이미지, 모호한 경로는 추정하지 않습니다.
문서 디렉터리 기준으로 검증된 Project 소스 내부에서만 경로를 풉니다. 루트 이탈,
외부/drive/UNC/stream 경로, 안전하지 않은 링크와 관리 namespace는 해당 링크만 거부합니다.
외부 URL을 다운로드하거나 World를 갱신하거나 정본을 쓰지 않으며 독립 작업은 계속 가능합니다.
